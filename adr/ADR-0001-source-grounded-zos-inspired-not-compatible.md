# ADR-0001: Source-Grounded z/OS-Inspired, Not Compatible

MFOS uses publicly available IBM-published z/OS / IBM Z documentation as
source-grounding input but does not claim z/OS or IBM product compatibility.
This reference use does not imply IBM approval, affiliation, sponsorship, or
endorsement.

Consequences:

- IBM-derived terms need Source Matrix IDs.
- MFOS divergence must be documented.
- Compatibility wording is prohibited outside non-compatibility or lint context.
