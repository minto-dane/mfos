# MFOS Legal-Risk Naming Policy

Status: draft

MFOS is an independent project. External product names may appear only in
source-reference, legal, non-compatibility, migration, or historical comparison
contexts.

MFOS-owned identifiers must not use external product names. IBM-derived
external references use the `EXTREF-IBM-*` namespace. Legacy `IBM-*` source IDs
are retained only as aliases in `legacy_source_ids` and the naming migration
report.

MFOS is not affiliated with, endorsed by, sponsored by, certified by, or
approved by IBM. MFOS does not claim compatibility with IBM products,
interfaces, record layouts, command syntax, macro interfaces, or documentation.

Public release requires human legal review. The current design scaffold is for
private internal use and technical review only.
