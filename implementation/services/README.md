# services/

Future MFOS enterprise service implementation area.

No Phase 1 work belongs here. Phase 1 is limited to Dafny executable-semantics
scaffold work and loader-only artifact validation under
`formal/executable-semantics/dafny/`.

Securityd, auditd, catalogd, datasetd, jobd, spoold, operatord, hosted service
adapters, hosted semantic prototypes, semantic runners, and production services
remain forbidden until a later implementation gate explicitly authorizes the
specific service scope with requirement IDs, source IDs, tests, audit
obligations, and evidence.
