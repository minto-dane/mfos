# Reports

This directory contains review, audit, validation, and phase-closure reports.

The root is intentionally small. Use `reports/index.yml` as the machine-readable
index and keep report files in the category directories below.

- `current/`: active PR, readiness, and decision reports.
- `phases/`: historical phase reports grouped by phase.
- `audits/`: domain audits grouped by audit type.
- `naming-safety/`: legal/naming migration and validation reports.
- `generated/`: deterministic reports regenerated by local scripts.
- `archive/`: superseded reports retained for review history.

Do not place new top-level reports directly under `reports/` unless the report
is an index or directory policy document.
