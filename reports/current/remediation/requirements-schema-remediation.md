# Requirements and Schema Remediation

Status: current

Existing requirement and schema validators pass. The remediation does not add
new current requirements for deferred domains. New namespaces such as
`MFOS-REQ-VIRT-*`, `MFOS-REQ-CVM-*`, `MFOS-REQ-CLUSTER-*`,
`MFOS-REQ-OPS-*`, `MFOS-REQ-PERF-*`, `MFOS-REQ-LANG-*`, and
`MFOS-REQ-FORMAL-*` are reserved in draft specs only and are not
implementation-ready.

Schema documentation now distinguishes existing JSON/YAML schema definitions
from future CUE and release-signing gaps.
