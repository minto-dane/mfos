# Non-Compatibility Statement

MFOS is z/OS-inspired and source-grounded.

MFOS is not:

- a z/OS-compatible operating system
- an IBM Z emulator
- a RACF-compatible security manager
- a JES-compatible job subsystem
- a DFSMS-compatible storage subsystem
- a Windows VBS clone

IBM terms may appear in source mappings, prohibited wording examples, and
semantic divergence notes. They must not be used as product compatibility
claims.
