# NIST Cache Manifest Guidance

Status: draft

NIST publications cited in this tree are public pages and DOI-backed
publications. Do not download NIST PDFs into this repository.

If a later policy explicitly permits an external cache, record metadata outside
the committed source tree or in a non-committed cache manifest:

- source ID
- publication page URL
- DOI URL
- PDF URL from the publication page, if needed
- retrieval date
- content digest of the cached local copy
- local cache path outside the repository
- reviewer initials or automation identity

Current NIST publication pages cited here:

- `NIST-160-001`: `https://csrc.nist.gov/pubs/sp/800/160/v1/r1/final`
- `NIST-193-001`: `https://csrc.nist.gov/pubs/sp/800/193/final`
- `NIST-218-001`: `https://csrc.nist.gov/pubs/sp/800/218/final`

The source cards remain public-safe bibliographic records and are not
substitutes for the NIST publications.
