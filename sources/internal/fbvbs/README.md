# FBVBS Internal Transfer Index

Source repository: `https://github.com/minto-dane/fbvbs`

Purpose: public-safe internal-transfer notes for MFOS. These cards paraphrase FBVBS assurance, state-machine, manifest, evidence, and transfer-rule patterns without importing large upstream text.

## Card Sets

- `source-cards/`: source-grounded summaries with upstream path references.
- `concept-cards/`: MFOS-facing concept abstractions derived from the source cards.
- `notes/`: transfer map, adopt/adapt/reject decisions, and gaps.

## Handling Rules

1. Treat FBVBS as source material, not as MFOS normative text.
2. Keep source quotations out of these files unless a future reviewer requests a narrow excerpt.
3. Preserve explicit gaps where the upstream source says closure is incomplete.
4. Any future MFOS requirement must point to an MFOS-owned design root, not only to FBVBS.
