# sources/

This directory is the top-level source-grounding layer.

Current v0.5 machine-readable Source Cards are under
[docs/design/source-matrix/cards](../docs/design/source-matrix/cards). This
directory adds the long-term source/concept-card structure without moving the
existing design artifacts.

Use this directory for:

- source cards
- concept cards
- mapping notes
- retrieval metadata
- citation and copyright policy

Do not store:

- copied IBM PDFs
- long quotations from external documents
- implementation code
- MFOS requirements without requirement IDs
