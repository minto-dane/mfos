# IBM External Reference Workbench

This tree contains public-safe MFOS source-grounding workbench artifacts for IBM-owned external documentation. It is not the canonical Source Matrix. The canonical source ledger remains `docs/design/source-matrix/` until an ADR migrates authority.

MFOS is independent and is not affiliated with, not endorsed by, not sponsored
by, not certified by, and not approved by IBM. Names in this tree are reference-only labels
for external documentation and do not imply compatibility with IBM products,
interfaces, record layouts, command syntax, macro interfaces, or documentation.

The artifacts here may contain URLs, retrieval metadata, MFOS mappings, divergence notes, prohibited inferences, and legal-control flags. They must not contain copied IBM documentation, tables, diagrams, record layouts, command syntax, macro interfaces, message catalogs, screenshots, PDFs, or HTML mirrors.
