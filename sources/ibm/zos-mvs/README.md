# IBM z/OS MVS Grounding

Public-safe MFOS grounding artifacts for z/OS MVS-adjacent job, spool, catalog,
and workload-management concepts. These cards are design-background mappings
only and do not claim JES, DFSMS, WLM, JCL, or z/OS compatibility.

## Index

- `source-cards/zos-mvs-source-cards.yml` - verified IBM source pointers and MFOS mappings.
- `concept-cards/zos-mvs-concepts.yml` - MFOS job, spool, catalog, and WLM concepts.
- `notes/public-safe-grounding-notes.md` - review notes, gaps, and negative tests.
