# Do Not Commit

This directory is ignored local scratch space. Keep authoritative metadata in
Source Cards, Concept Cards, retrieval logs, and the current canonical
`docs/design/source-matrix` records.

Never commit downloaded source documents from IBM or any other public source.
Never commit local PDF text extraction, HTML mirrors, screenshots, copied
tables, copied diagrams, command syntax, macro signatures, message catalogs,
record layouts, or long excerpts.

Local cache manifests may record retrieval facts, checksums, source URLs,
review dates, and purge status. They must not contain copied source content.
